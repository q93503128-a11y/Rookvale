# Rookvale

Rookvale is a multiplayer-first 2D pixel open-world RPG being designed for the web first, with future portability to Roblox and mobile in mind.

## Current direction

- Explore a large handcrafted fantasy world with towns, fields, dungeons, encounters, and varied activities.
- Enter turn-based battles from the overworld.
- Support solo play and multiplayer parties as a core design assumption.
- Build meaningful party roles such as damage, tanking, healing, support, control, and hybrid roles.
- Use branching class advancement rather than a single linear class ladder.
- Keep the visual direction pixel-based, readable, attractive, and flexible rather than locking into a specific cute/dark style too early.
- Treat Hero of Aethric as a reference for the broad overworld-to-turn-based-battle structure only; other systems and presentation should be researched independently from multiple games.
- Build the web version as the source implementation while keeping game data, assets, UI layout rules, and gameplay specifications portable to Roblox and mobile.

## Project status

**Phase:** pre-production / collaborative game design

No final combat system, class tree, world structure, economy, content cadence, or production scope has been locked yet. These will be decided collaboratively before implementation expands.
