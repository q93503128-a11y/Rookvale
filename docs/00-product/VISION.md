# Product Vision

**Status:** Draft

## One-line definition

Rookvale is a multiplayer-first 2D pixel open-world fantasy RPG where players explore a large handcrafted world and transition into strategic turn-based battles alone or with a party.

## Locked direction so far

- Web is the source implementation.
- Roblox and mobile are intended future targets and should influence architecture from the start.
- The overworld is a real game world, not GPS-based.
- Exploration happens directly in the world before entering turn-based encounters.
- Multiplayer is a foundational assumption, not a late optional feature.
- Party composition should make roles such as damage, tanking, healing, support, control, and hybrids meaningful.
- Character progression should include branching class advancement.
- The world should contain a starting settlement, broad explorable regions, varied enemies, and multiple kinds of activities/content.
- Visuals are pixel-based. The exact tone may be cute, adventurous, darker, or mixed as long as the result is attractive and coherent.

## Reference boundary

Hero of Aethric is a reference for the broad pattern of exploring a 2D world and entering turn-based RPG encounters. It is **not** the template for every other system. Combat, progression, multiplayer, UI, content, economy, presentation, and social systems should each be researched independently.

## Experience goals

Rookvale should make players want to:

- see what is beyond the next area;
- find stronger or stranger enemies and content;
- build a character with a recognizable role and play style;
- group with other players because cooperation changes tactical options, not merely numbers;
- return to earlier places for new reasons rather than only progressing through a disposable linear map;
- understand important information quickly despite having a deep RPG underneath.

## Non-goals for now

These are intentionally not decided yet:

- exact monetization;
- PvP design;
- exact maximum party size;
- exact class count;
- exact map size;
- exact art palette or setting tone;
- exact combat gimmick;
- exact endgame structure.
